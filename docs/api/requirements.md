# 이커머스 서비스 요구사항 명세서

## 1. 프로젝트 개요
상품 관리, 주문/결제, 쿠폰 시스템을 포함한 이커머스 핵심 기능 구현

## 2. 핵심 기능

### 2.1 상품 관리

#### 상품 조회
- 상품 상세 정보 조회 (상품명, 가격, 재고, 설명)
- 상품 목록 조회 (페이징)
- 실시간 재고 확인

#### 인기 상품 통계
- 최근 3일간 판매량 기준 Top 5 조회
- 주문 수량 기준 집계

### 2.2 주문/결제

#### 장바구니
- 상품 추가/삭제
- 총 금액 계산

#### 주문 처리
- 재고 확인 및 차감
- 재고 부족 시 주문 실패
- 여러 상품 동시 주문

#### 결제
- 잔액 기반 결제
- 쿠폰 할인 적용 (1개만 사용 가능)
- 잔액 부족 시 결제 실패
- 결제 실패 시 재고 복구

### 2.3 쿠폰

#### 발급
- 선착순 한정 수량 발급
- 중복 발급 불가

#### 사용
- 유효성 검증 (소유 여부, 유효 기간, 사용 여부)
- 1회 사용 후 재사용 불가
- 사용 이력 기록(쿠폰 상태)

### 2.4 잔액 관리
- 잔액 조회
- 잔액 충전

### 2.5 데이터 연동
- 주문 완료 시 외부 시스템으로 데이터 전송
- 전송 실패 시에도 주문은 정상 처리

## 3. 기술 요구사항

### 구성
- Spring Boot
- MySQL
- Redis

### 동시성 제어
- 재고 차감 시 동시성 보장
- 쿠폰 발급 시 수량 초과 방지

### 트랜잭션 처리
- 재고 차감과 주문 생성 원자성 보장
- 결제 실패 시 재고 복구

### 보안
- 사용자는 본인의 데이터만 조회/수정 가능
